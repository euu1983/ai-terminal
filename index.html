AI Terminal

Mobile-first terminal for AI coding agents. Built for Claude Code & Codex CLI. Multi-session tabs, AI-native keyboard, self-hosted relay support.

Request Beta Invitation

Core Features

AI-Native Virtual Keyboard

esc, ctrl, arrow keys, tab, copy/paste, file upload, ^C — designed for AI prompts on mobile, not generic terminals.

Multi-Session Tabs

Jump between repos in one tap. Each tab is its own session with isolated state.

Self-Hosted Relay

Run your own relay server. Your code stays on your infrastructure — you choose what leaves it.

Works with Leading AI Coding Agents

Out-of-the-box support for Claude Code and OpenAI Codex CLI. No model lock-in.

Install daemon on your computer

One-line install. The daemon shows a QR code; scan it with the mobile app to pair.

curl -fsSL https://dist.ai-terminal.org/install.sh | bash
irm https://dist.ai-terminal.org/install.ps1 | iex
